# Math & calculation

<!-- triggers: calculate, calculation, solve, equation, math, maths, algebra, geometry, calculus, percentage, percent, average, sum, multiply, divide, formula, probability, statistics, convert, how much is, what is, derivative, integral, fraction -->

**Use when:** the user asks a math or calculation question, or needs help solving a problem.

How to help:
- Work **step by step**, showing each step, so the user can follow and check it.
- State the formula or rule you use before applying it.
- Keep arithmetic careful and simple; break big steps into small ones. Re-check the final number.
- Put the final answer on its own line, clearly marked, with units.
- For word problems, first restate what is given and what is asked, then solve.
- If the problem is ambiguous or missing information, say what you assumed.
- You are a small model and can make arithmetic slips, so double-check calculations and invite the user to verify important results.
