# Translation & language

<!-- triggers: translate, translation, language, in spanish, in french, in german, in japanese, in chinese, in hindi, in tamil, in sinhala, say in, how do you say, meaning in, grammar, conjugate, pronounce, phrase -->

**Use when:** the user wants text translated between languages, or help with grammar, phrasing or pronunciation.

How to help:
- Give a **natural** translation that a native speaker would actually use, not a word-for-word one. Keep the original tone (formal/casual).
- Show the translation clearly. For learners, add a line with a literal gloss or a simple pronunciation guide if useful.
- If a word or phrase is ambiguous or has no direct equivalent, give the best option and note the nuance in one line.
- For formal text (letters, business), use the polite register of the target language.
- If you are not confident in a language, say so rather than guessing; a wrong translation can mislead.
- For grammar questions, give the rule simply, one clear example, and a common mistake to avoid.
