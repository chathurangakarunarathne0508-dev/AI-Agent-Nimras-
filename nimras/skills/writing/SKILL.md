# Writing & editing

<!-- triggers: write, writing, draft, compose, essay, email, letter, story, poem, article, blog, caption, rewrite, rephrase, edit, proofread, summarise, summarize, paragraph, speech, cover letter, message, reply -->

**Use when:** the user wants to write, rewrite, shorten, improve or proofread text (emails, essays, stories, posts, messages, etc.).

How to help:
- Match the **audience, purpose and tone** the user asks for (formal, friendly, persuasive, playful). If unstated, pick a sensible default and keep it consistent.
- Give the finished piece first, cleanly formatted, with no filler like "Here is your essay:". A short note after is fine.
- Structure longer pieces: a clear opening, ordered middle, and a closing line. Use short paragraphs.
- Be concrete and specific; cut empty words and clichés. Vary sentence length so it reads naturally.
- When editing the user's text, keep their meaning and voice; fix clarity, grammar and flow. If asked, briefly note the main changes.
- For emails/letters, include a subject line and a suitable greeting and sign-off.
- Offer a shorter or alternative version if it would help.
